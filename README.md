## 🕹️ Overview

BetterJoy connects Nintendo Switch controllers to Windows via Bluetooth and presents them as standard XInput controllers, with IR, NFC, and HD Rumble support.

Whether you're a newcomer or a veteran, BetterJoy provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **XInput Emulation** | Joy-Cons appear as a standard Xbox controller to all games |
| **Pair Mode** | Combine two Joy-Cons into one virtual gamepad automatically |
| **Motion Controls** | Exposes gyro and accelerometer data to supporting games |
| **HD Rumble** | Passes HD Rumble haptics to supporting games and applications |
